# 📊 Retail Sales Analytics | Data Analytics Portfolio Project

## 📌 About the Project

This project was developed to simulate a real-world retail analytics environment.

It covers the entire analytics workflow, from dataset creation and dimensional modeling to Data Warehouse implementation, SQL analysis, and Power BI dashboard development.

The dataset contains more than 49,000 sales records distributed over a 5-year period, enabling temporal, geographic, financial, and customer behavior analysis.

---

## 🎯 Project Goals

- Build a Data Warehouse using Star Schema modeling
- Apply ETL and data transformation processes
- Develop analytical SQL queries
- Create executive dashboards in Power BI
- Generate business insights from data
- Showcase SQL, BI, and Analytics skills

## 📊 Data Model

The project follows a dimensional Star Schema design.

### Fact Table

**Sales**

Metrics:

- Net Revenue
- Profit
- Quantity Sold
- Discount
- Average Ticket
- Margin

### Dimensions

- Product
- Store
- Customer
- Payment Type
- Sale Type
- Calendar
