# 📊 Retail Sales Analytics | Data Analytics Portfolio Project 

## 📌 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de simular um ambiente corporativo de análise de dados para o setor varejista.

O projeto contempla todo o fluxo analítico, desde a construção da base de dados, modelagem dimensional, criação do Data Warehouse, análises em SQL Server e desenvolvimento de dashboards executivos no Power BI.

O dataset contém mais de 49 mil registros de vendas distribuídos ao longo de 5 anos, permitindo análises temporais, geográficas, financeiras e comportamentais.

---

## 🎯 Objetivos

- Construir um Data Warehouse utilizando modelagem estrela (Star Schema)
- Aplicar processos de ETL e tratamento de dados
- Desenvolver consultas analíticas em SQL
- Criar dashboards executivos no Power BI
- Gerar insights de negócio baseados em dados
- Demonstrar habilidades em SQL, BI e Analytics
